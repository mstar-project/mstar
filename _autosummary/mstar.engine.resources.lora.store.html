mstar.engine.resources.lora.store#

The host tier of the adapter pool: adapters read, sharded for this rank, and pinned.

An adapter’s tensors are laid out exactly like one device slot (rank padded to the pool’s max_rank with zeros), so moving it onto the device is one copy per target.

class mstar.engine.resources.lora.store.LoadedAdapter(name, digest, rank, scaling, a, b)[source]#

Bases: object

One adapter, ready to copy into a slot.

a[target] is [target layers, slices * max_rank, in] and b[target] is [target layers, out, max_rank], both already this rank’s shard. A target the adapter does not touch is absent. digest is adapter_digest of the unsharded weights, so every rank agrees on it, computed as the API server computes the one it roots the adapter’s prefix-cache keys in.

class mstar.engine.resources.lora.store.LoraAdapterStore(spec, rank=0, world_size=1, pin=None, dtype=None)[source]#

Bases: object

Adapters held in pinned host memory.

Which adapters it holds follows from the hold calls alone, in their order: each makes an adapter the most recent, dropping the least recent past capacity but none the call’s keep names. A held adapter’s copy arrives later, by put, once read. So when a read lands or fails never changes what is held, and ranks that make the same calls hold the same set.

path read, checked against the spec and sharded for this rank, without holding it: a caller can read outside whatever lock guards put. With digest, weights that digest otherwise are refused: the file changed since the adapter was checked and keyed, and serving it would put other weights under the same prefix-cache root, or different weights on different ranks.

mstar.engine.resources.lora.store.check_adapter_file(spec, name, path, others=())[source]#

The adapter at path checked against spec and the model’s others (its LoRA specs for other nodes, a vision tower’s say, which serve the same adapters), each from the checkpoint’s header; returns its digest. The digest is read once per way the specs convert the checkpoint (convert_keys), so once for specs that read it alike. Raises ValueError for an adapter the deployment cannot serve.

mstar.engine.resources.lora.store.check_adapters(spec, others=())[source]#

Every adapter spec serves, through check_adapter_file (against others too); returns each one’s digest.

Raises naming every adapter that fails, so a bad adapter in the serving config stops the deployment at startup, the same whether or not a worker would have preloaded it.
