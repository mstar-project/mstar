mstar.model.components.diffusion.text_encoder#

Native Qwen3-family prompt encoder that returns tapped hidden states.

FLUX.2 [klein] and Z-Image condition their DiTs on intermediate hidden states of a Qwen3 language model (klein: layers 9/18/27 of Qwen3-4B/8B concatenated), not on its logits. This module is that encoder built from M*’s transformer components: DecoderLayer + GatedMLP + an HF-order RMSNorm with a GQA attention that carries per-head q/k RMSNorm and plain RoPE, run only through the deepest tapped layer (klein skips the last quarter of the LM).

Prompts arrive right-padded to one length (the pipelines pad to max_sequence_length and feed every position, pad tokens included, to the DiT), so the padded positions’ hidden states must be exactly what the reference LM computes for them: a query at position i attends causally to keys <= i that are not padding. That mask is built once per batch and handed to SDPA, the reference’s own kernel.

class mstar.model.components.diffusion.text_encoder.Qwen3RMSNorm(dim, eps)[source]#

Bases: Module

RMSNorm in the HF Qwen3RMSNorm rounding order: normalize in fp32, round to the input dtype, then multiply by the weight. In bf16 this is bit-exact with the reference encoder; mstar.model.components.RMSNorm rounds rsqrt first (portable path) or the whole product once (FlashInfer kernel), and either differs in the last bit, which the 27 to 35 layers below a tap then amplify.
