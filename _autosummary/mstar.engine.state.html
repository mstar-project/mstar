mstar.engine.state#

The model-facing state contract. __all__ is its whole surface, and after release the surface only grows.

class mstar.engine.state.Array(name, *, nodes, layers, entry, max_len, reads=FrozenMap({}), updates=FrozenMap({}), rewritable=False, labels=frozenset({'main'}), positions=None)[source]#

Bases: object

Per request, per label and per declared layer, entries at log positions 0 to n - 1, with n <= max_len.

An append-only array only grows, and a rewritable one also takes writes in place. All layers of an array have the same length at the end of every step. nodes lists who may touch the array, and the engine places it. updates are kernels that replace a Value’s entry with its next version. The version they overwrite is gone, so prefix caching and undo save a copy before one runs. With max_len 0 an array keeps nothing between steps, so every add is scratch.

class mstar.engine.state.SeqShard(name, *, nodes, labels=frozenset({'main'}), walks=None, exchange='auto')[source]#

Bases: object

A node’s steps may split over its SP ranks: per step, the engine decides from the step whether labels’ tokens split, each rank running the token-local layers on its share, or are copied. A layer stack calls scatter before and gather after; at one SP rank, and on a copied step, both pass their inputs through. Reads and updates of the node’s arrays exchange what a split step needs by themselves.

labels lists one label, which an array on nodes opens, since the shard’s handle brackets one; a node with no arrays declares a SeqShardSpec itself. The shard cuts the label’s tensors as the node’s reads take queries on it: rows of one span (Read.packed False, not segmented) each row alike, packed tokens or a request’s segments in one row contiguously; the reads take one of the two. walks are the walks whose steps may split, as a row’s walk (a combined walk splits where a walk it combines is listed); None: every walk. exchange is the author’s default for how a split step reaches the node’s paged attentions, which the deployment’s resources: block overrides under the shard’s name: auto (Ulysses over KV stored by head, copied over KV stored by position), none (never split), ulysses, all_gather or ring.

class mstar.engine.state.Span(kind, walk, length, advance, source, params=(), scratch=0, opens_step=True)[source]#

Bases: NamedTuple

One write to a KV stream. A layout lists them in the order the walks write.

Each span is one step’s row, unless a span sets opens_step False: the step of the span before it then writes it too, in the same row, as text around an attachment is. That span is of the same walk, since a step runs one.

length is how many KV slots the write fills, and advance is how far it moves the position counter, which is the length for text. source is the tensor whose next entry an ids span keys, or the file of a digest span as (modality, index). params are the preprocessing arguments that change the tensors made from the file. A rows span writes KV made from anything else, such as another node’s outputs, and is never keyed. scratch is the most a non-committing step writes before the span commits into those slots, as a denoised window does.
