class mstar.model.utils.ByteLevelDetokenizer(tokenizer, keep_special=False)[source]#

Bases: object

Byte-faithful per-token detokenization for byte-level BPE tokenizers (GPT-2 / Whisper / Qwen).

Streaming models emit one token per step to the client, so a multi-byte UTF-8 character split across tokens must be emitted as raw bytes and reassembled client-side — per-token tokenizer.decode would yield U+FFFD for each partial character.

Special tokens are dropped, like skip_special_tokens, unless keep_special: then the joined bytes of any id sequence decode to what tokenizer.decode(ids) gives.

class mstar.model.utils.TextChunkDetokenizer(tokenizer)[source]#

Bases: object

One decode step’s text chunk for a model that streams a token per step.

With a byte-level tokenizer the chunk is the tokens’ raw bytes, special tokens kept, so a character split across steps reassembles in the API server’s incremental decoder and the joined reply equals tokenizer.decode of all its ids. Any other tokenizer keeps the per-step decode.

mstar.model.utils.check_kv_pools_fit(model, config, config_path, log)[source]#

Refuse a max_concurrent_requests the model’s KV caches cannot hold.

A request keeps its pages from prefill to its last token. Past a pool, a prefill batch is refused and the worker offloads decoding requests to admit it, which costs far more than queueing would. So the cap’s requests at full length must fit each cache next to its sink page; the conductor queues the rest. Warnings go to the model’s log.

mstar.model.utils.drop_stop_tokens(output, stop_token_ids, request_kwargs)[source]#

Drop the stop tokens that ended a text reply, unless the request sets ignore_eos.

A stop token ends the turn, not the reply: a client sends the reply back as an assistant message, whose template closes it. Under ignore_eos it ends nothing and stays, one chunk per token.

mstar.model.utils.load_generation_defaults(checkpoint_dir, prefix='', stage='')[source]#

The sampling defaults checkpoint_dir/generation_config.json declares.

Keys come back under mstar names (max_new_tokens -> max_output_tokens). prefix selects one stage’s keys in a multi-stage file ("talker_" reads talker_temperature) and stage prefixes the returned names ("code_predictor_"). do_sample: false is greedy: temperature 0. Returns {} when there is no file, so the caller’s own defaults apply.

mstar.model.utils.load_weights_from_hf_shards(repo_dir, modules, device='cpu', conv=None)[source]#

Load weights from a HuggingFace safetensors checkpoint.

Reads model.safetensors.index.json to find which shard each key lives in, then loads from each shard file. Checkpoints that ship a single unsharded model.safetensors (no index — e.g. whisper-large-v3) are handled by treating that one file as the whole weight map.
