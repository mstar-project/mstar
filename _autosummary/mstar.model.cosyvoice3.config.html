mstar.model.cosyvoice3.config#

Configuration for Fun-CosyVoice3 (FunAudioLLM/Fun-CosyVoice3-0.5B-2512).

The checkpoint ships a hyperpyyaml file (cosyvoice3.yaml) that builds the reference classes directly; there is no config.json. The dataclasses below write its values down once. Every shape they declare is checked against the checkpoint when the weights load.

Sources (read, not copied): cosyvoice3.yaml from the HF snapshot and cosyvoice/{llm/llm.py,flow/flow.py,flow/flow_matching.py,flow/DiT/*, hifigan/generator.py,hifigan/f0_predictor.py,cli/model.py,cli/frontend.py} from FunAudioLLM/CosyVoice.

The reference-audio front end is Chatterbox’s: the 25 Hz speech tokenizer v3 is Chatterbox’s S3Tokenizer with twelve blocks instead of six, the speaker encoder is the same CAMPPlus, and the prompt mel is the same 24 kHz Matcha mel with fmax left at Nyquist. Their configs are Chatterbox’s dataclasses.

Repetition-aware sampling (cosyvoice.utils.common.ras_sampling): a nucleus draw (top-p over at most top-k ids); a draw that already appears >= ras_window * ras_tau times in the last ras_window tokens is masked and redrawn from the full distribution.
