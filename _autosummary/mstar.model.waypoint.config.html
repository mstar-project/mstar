mstar.model.waypoint.config#

Configuration for Waypoint-1.5 (autoregressive video world model).

Hardcodes the published 720P/360P checkpoint manifests so constructing the model never touches the network. Attention geometry is per-layer heterogeneous (local vs. global window; see global_layers / ring_frames), and each frame costs 4 non-committing Euler passes plus 1 committing pass that writes the settled K/V into the ring.

Functions

waypoint_1_5_1b_360p()

The 360P checkpoint: 128 tokens/frame over a 16x32 latent grid.

waypoint_1_5_1b_720p()

The default checkpoint: 512 tokens/frame over a 32x64 latent grid.
