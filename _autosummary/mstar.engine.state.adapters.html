mstar.engine.state.adapters#

The glue between declarations and today’s resources, as one layer: a storage per kind of array, a binding per storage and op type, and a handle per storage. It builds the specs, steps and layouts everything downstream reads.

Functions

build_handle(declared, resources)

declared's handle over the built resources, with each of its ops bound.

build_specs(declarations, *[, kernel_settings])

Each array's specs, from its storage and its ops' bindings, under the names the declarations give, then a PositionSpec for each array that declares positions and a SamplerSpec per sampler.

kv_layouts(declarations, state_layout, ...)

Today's LabelLayout per paged array and label, from what a model's process_prompt returned.

node_handles(model, node, resources)

node's handles, by declared name, over its built resources.

node_resources(model)

The specs model declares through declare_state, then the ones it writes by hand.

sampling_configs(configs, declarations)

configs with each SampleSettings as today's SamplingReqConfig.

state_steps(step, handles)

step as a new step, with what its state declares expanded into today's step objects, built afresh for each step because SubmoduleStep writes the segments onto them.

storage_of(array)

The storage today's resources keep array in.

add(layer, *, keep=None, **fields)[source]#

Append each row’s span at its next log positions. A kept add happens once per layer per step, as the layer’s last add. keep False is scratch: it can repeat, and lasts until the next add or the end of the step. None takes the step’s keep. The resources keep or drop a step’s adds as a whole, so a step that keeps needs each layer to end on a kept add, and a step with keep False refuses keep=True.

Each array’s specs, from its storage and its ops’ bindings, under the names the declarations give, then a PositionSpec for each array that declares positions and a SamplerSpec per sampler.

Raises ValueError on an array today’s specs can’t hold, naming what they lack. That includes a second update of one type on an array, a temporary limit: an update call finds its op by type, which today’s resources need and the contract doesn’t.

mstar.engine.state.adapters.kv_layouts(declarations, state_layout, keyed_spans)[source]#

Today’s LabelLayout per paged array and label, from what a model’s process_prompt returned. Any other array’s layout is dropped: a Value’s pool reserves a slot per label, and an array with max_len 0 keeps nothing.

The model is at fault for a name it doesn’t declare, so this raises RuntimeError, which fails the request with a 500, as refuse_undeclared_labels does.
