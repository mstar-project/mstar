The Python API reference is generated from module docstrings by Sphinx. It follows
the package layout under `mstar/`, with subpackages, modules, classes, and functions.

  Browse the generated reference on the existing documentation site.
</Card>

The generated reference remains on the Sphinx site while the narrative guides move
to Mintlify. Python symbol links in these guides open their source module on GitHub.

## Building the reference

Sphinx imports the modules to read their docstrings, so the reference build needs
the project's runtime environment (`pip install -e ".[dev]"` plus
`docs/requirements.txt`), including PyTorch and the other core dependencies.
See [the Sphinx configuration](https://github.com/mstar-project/mstar/blob/main/docs/conf.py)
and [documentation workflow](https://github.com/mstar-project/mstar/blob/main/.github/workflows/docs.yml)
for the build configuration.
