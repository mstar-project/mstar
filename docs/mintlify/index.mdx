## From request to result

A model declares a graph of components, such as an encoder, a transformer, or an audio decoder. Each request follows graph walks through those components. The deployment YAML assigns nodes to GPU ranks, so supported placement changes do not require rewriting the model.

```mermaid
flowchart LR
    Client[HTTP / SDK] --> API[HTTP frontend and Python preprocessing]
    API --> Conductor[Conductor]
    Conductor --> Workers[GPU workers]
    Workers --> Results[Streamed results]
    Results --> Client
```

The conductor coordinates graph walks; workers execute ready nodes and return results. Read [Architecture](/architecture) for the execution flow and resource ownership, or [Adding models](/adding_models) to implement a model.
